1. querySelector() :
=> En JavaScript, la méthode querySelector() permet de sélectionner et de récupérer le premier élément du DOM
2 .addEventListener() :
=> une fonction ou un objet en programmation qui écoute ou attend qu'un événement particulier se produise sur un élément.
3. createElement() :
=>  c'est une méthode qui permet de créer un nouvel élément HTML en mémoire.
4. appendChild () :
=> est une fonction du DOM qui permet d'ajouter un element en tant que dernier enfant d'un élément parent.
5. preventDefault() :
=> c'est un permet d'annuler le comportement par défaut qu'un navigateur Web associe à un événement
6. innerHTML :
=> permet de lire ou de modifier le contenu HTML (texte et balises) d'un élément du DOM .
7. DOM :
=> c'est une interface de programmation qui représente une page web en HTML  sous forme d'un arbre d'objets ou de nœuds.
8. evnet.target :
=> est une propriété qui renvoie l'élément DOM exact sur lequel l'événement s'est produit.
9. evenment en js :
=>  un signal envoyé par le navigateur lorsqu'il se passe quelque chose sur une page Web .
10. textContent () :
=> il permet de lire ou de modifier le texte brut d'un élément du DOM et de tous ses descendants, sans interpréter les balises .
11. closest() :
=> est une méthode du DOM qui permet de rechercher l’élément le plus proche correspondant à un sélecteur CSS, en partant de l’élément sélectionné et en remontant dans ses parents.
12. contains() :
=> La méthode permet de vérifier si un élément DOM contient un autre élément, directement ou indirectement. Elle retourne true si l’élément est contenu dans l’autre, sinon elle retourne false.
